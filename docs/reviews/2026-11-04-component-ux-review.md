# Duet 컴포넌트별 UX 리뷰 (1차: 탭 · 패널 크롬 · 연결 · 사이드바/셸 · 파일 보기)

2026년 11월 3–4일. 사용자가 짚은 "미묘한 불편"(숨김 토글이 한 단계 아래로 내려감, 현재 탭이 원격인지 알기 어려움,
탭 핀 고정 없음, 배너 재연결 후 "어느 패널에 띄울까"를 다시 물음)을 출발점으로, 컴포넌트 5개를 병렬로 리뷰·구현·검증했다.

## 진행 방식

- 컴포넌트마다 git worktree(`ux/<comp>`)와 herdr 워크스페이스 1개(탭 1개를 3분할)를 두었다.
  리드 Claude Opus 5.5가 계획·구현을 맡고, 워커 Claude Opus 5.5와 Codex GPT-6.1-Sol이 독립 리뷰와 병렬 검증을 맡았다.
  메인 세션은 오케스트레이터로서 팀 간 중복 조율, 통합, 실앱 스모크를 맡았다.
- 단계: 독립 리뷰 3건 → 계획(plan.md) → 리드 구현 → 워커 2명 병렬 검증(게이트 + 스모크, 최대 3라운드) → 최종 보고.
- 팀 간 중복은 진행 중에 조율했다(alias 파싱 헬퍼 공유, 탭 전환 새로고침 effect는 tabs, 사이드바 상태 점은 sidebar-shell).
- 팀별 계획·검증 보고서 원본: `../duet-ux/_orchestra/<comp>/{plan,final}.md`, 워커 보고서: `reports/`.

## 통합

순서: connection → pane-chrome → sidebar-shell → file-view → tabs. tabs는 리드가 먼저 `ux/connection`을 병합해 충돌을 풀었다.

- `stores/panes.ts`: 숨김 토글 커서 유지가 pane-chrome·file-view 양쪽에 있었다. file-view의 `keepCursor` 판(숨겨진 선택 해제 포함)으로 정리하고, tabs의 핀 헬퍼와 합쳤다.
- `PathBar.tsx`: 소스 칩은 tabs의 `SourceChip`, 경로 바 기능(현재 폴더 클릭 편집·경로 복사)은 pane-chrome 쪽을 따랐다.
- 합친 뒤에야 드러난 테스트 결함 2건을 고쳤다(제품 코드 무변경): savedHosts의 i18n import 때문에 연결 대화상자 테스트의 react-i18next 모킹 보강, ContextMenu `role="menuitem"` 변경에 맞춰 tabs 스모크 헬퍼 수정.

## 검증

- 통합 브랜치(`3f913ff`, 현 main): tsc, eslint, prettier, **Vitest 75 files / 581 tests**, vite build, cargo fmt·clippy(-D warnings)·**cargo test --lib 370 통과(1 ignored)**.
- 실앱: `pnpm tauri dev`로 빌드·실행했고 런타임 오류 로그는 없었다. 이 환경에는 화면 기록·손쉬운 사용 권한이 없어 창 캡처와 조작은 하지 못했다.
- 시각 스모크(대체): 실제 `App`을 Vite + 헤드리스 Chrome으로 렌더하고 IPC는 스모크 테스트와 같은 방식으로 모킹했다. 라이트 모드에서 다음을 확인했다.
  - 툴바 숨김 토글의 1클릭 노출(좁은 창 포함)과 켜짐 배경
  - 핀 탭(왼쪽·핀 아이콘), 원격 탭·경로 바 호스트 칩, 비활성 원격 탭의 끊김 아이콘
  - 끊긴 패널의 배너(사유 + [재연결]), 상태바 원격 표시·숨김 개수
- 실제 SSH 서버 왕복과 Windows 실기는 하지 않았다. Docker daemon이 꺼져 있어 `scripts/ssh-it.sh`도 미실행이다.

## 이번에 새로 발견한 문제 (미수정)

1. **개발 빌드에서 세션 복원 활성 탭이 틀어진다.** React StrictMode가 부트스트랩 effect를 두 번 실행하고, 두 실행이 겹치면서
   두 번째 실행이 첫 실행 루프가 바꾼 activeTabIndex를 "저장된 값"으로 읽는다(`App.tsx` 부트스트랩의 `savedActive`).
   main에도 원래 있던 코드다. 프로덕션 빌드는 effect를 두 번 돌리지 않으므로 dev 전용으로 보이지만, 부트스트랩을 멱등하게 만드는 편이 안전하다.
2. 끊긴 원격 패널이 배너 아래에 "빈 폴더입니다"를 표시한다. 비어 있는 게 아니라 연결이 없는 것이다. 문구를 구분할 것을 권한다.

## 2차: dialogs-palette (대화상자 · 명령 팔레트 · 검색 · 설정)

- 주요 수정:
  - 한글 IME 조합 중 Enter 오발동
  - 모달이 떠 있을 때 뒤 패널로 명령·목록 키가 새는 문제
  - 키맵 편집: Esc 가 설정 창을 닫음, 충돌을 알리지 않음, 가려진 기본 키가 그대로 표시됨
  - 권한 혼합 선택 시 폴더 x 비트 상실(위험 차단)
  - "할 일 없음" 상황에 피드백이 없음
  - 토스트가 모달에 가려짐
- 검증: R1 두 워커 FAIL(회귀 2건 포함) → 수정. R2 sol FAIL(P2 1건) → 수정. **R3 opus·sol 모두 PASS.**
  main 반영 전 재실행 결과: tsc·eslint·prettier 0, **Vitest 84 files / 626 tests**, vite build 성공.
  새 회귀 테스트는 수정 전 코드에서 실패하는 것을 확인했다(12파일 35건).
- 실앱·시각 스모크는 이 라운드에서 따로 하지 않았다. 동작은 키보드·IME 흐름 위주라 RTL 스모크(`__smoke__/dialogs-palette.smoke.test.tsx`)로 검증했다.
