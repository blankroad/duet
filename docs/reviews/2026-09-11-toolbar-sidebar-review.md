# 도구 모음·사이드바 발견성 개선 — 2026-09-11

이전 보고서에 남긴 도구 모음의 넘침 처리, 작업 라벨, 사이드바 빈 상태 안내를 반영했다.

- 패널 폭 560px 미만: `보기` 메뉴에서 상세/그리드/타일, 동기화 브라우징, 숨김 파일을 선택한다.
  현재 보기와 켜진 설정은 체크로 표시한다. 좁은 도구 모음을 가로 스크롤할 필요가 없어졌다.
- 넓은 패널: 기존 보기 바로가기 버튼을 유지하고 복사/이동/삭제에 글자 라벨을 표시한다.
  새 폴더는 모든 폭에서 글자로 표시한다.
- 메뉴는 기존 ContextMenu를 재사용해 방향키·Enter·Escape와 화면 가장자리 위치 보정을 따른다.
  숨김 파일 단축키는 기존 commandId로 조회하므로 사용자 변경을 반영한다.
- 파일 작업 버튼은 마우스뿐 아니라 키보드 클릭에도 해당 패널을 먼저 활성화한다.
  휴지통 삭제·확인 다이얼로그 등 기존 파일 작업 경로를 유지한다.
- 빈 호스트 목록에는 `호스트 연결`, 빈 북마크에는 `현재 폴더 추가` 버튼을 제공한다.
  최근 항목에는 방문한 폴더가 자동으로 표시된다는 안내를 넣었다.

## 확인

실제 컴포넌트 + mock 데이터의 Chrome headless 화면으로 확인했다.

| 화면 | 결과 |
|---|---|
| 800×600 다크/한글, 미리보기 켜짐 | 도구 버튼과 보기 메뉴가 패널 안에 들어옴. 펼친 메뉴도 화면 안에 표시 |
| 800×600 라이트/영문, 보조 패널 저장 폭 최대 | `New folder`와 `View`, 사이드바 연결·추가 버튼이 잘리지 않음 |
| 1440×800 라이트/영문, 사이드바 닫힘 | 작업 글자 라벨과 기존 보기 버튼이 함께 표시 |

검증: TypeScript·ESLint·프런트엔드 테스트 49개 파일/329개 통과.
추가 테스트는 키보드 파일 작업의 대상 패널, 보기 메뉴 키보드 선택, Escape 취소를 확인한다.
최종 메뉴 문구 변경 후 해당 테스트 3개를 재실행했다. Vite 프로덕션 빌드도 확인했다.
