# 알림 시각 점검 및 수정 — 2026-09-11

토스트·연결 배너·작업 표시줄·모달 공통 셸·경고 밴드·진행률 수치를 점검했다.

| 문제 | 수정 |
|---|---|
| 공백 없는 긴 경로가 토스트 본문의 최소 폭을 키워 X를 밀어냄 | 본문 min-width:0, anywhere 줄바꿈, 화면 폭 안에서 최대 28rem |
| 긴 오류 4개가 쌓여 위 카드가 잘림 | 화면 높이와 최대 4개를 고려한 본문 높이 제한, 본문 스크롤, 극소 높이에서는 스택 스크롤 |
| X 클릭 영역이 작음 | 24×24px 고정, 포커스 표시, 닫기 라벨 번역 |
| 모달 긴 제목·경고가 넘치거나 푸터가 좁아짐 | 창 좌우 여백, 긴 단어 줄바꿈, 헤더/푸터 축소 방지, 버튼 줄바꿈 |
| 작업 표시줄의 긴 이름·수치가 취소 버튼을 압박 | 이름/수치 축약, 취소 버튼 고정, 좁은 폭에서 게이지 축소 |
| 연결 상태의 긴 이름이 조작부를 압박 | 이름 축약·전체 툴팁, 재연결 버튼 최소 높이 |
| 진행률 수치가 한 줄 폭을 초과 | 크기·속도·ETA 행 줄바꿈 |

실제 React 컴포넌트와 프로젝트 Tailwind CSS를 임시 fixture에 번들해 Chrome headless에서
확인했다. 새 의존성은 설치하지 않았다. 원격 연결과 실제 파일 작업은 실행하지 않았다.

- 토스트: 공백 없는 긴 경로, 여러 줄 오류, 4개 누적, 라이트/다크.
- DOM 측정 viewport: 640×457 및 500×457. 가로 넘침 없음, 토스트 X 4개 모두 화면 안,
  클릭 영역 각각 24×24px.
- 모달: 500×457에서 큰 폭 프리셋과 긴 경고 본문. 취소/실행 버튼 화면 안, 본문 스크롤.
- 420px 브라우저 창 요청은 Chrome의 실제 viewport가 500px여서 420px 검증으로 세지 않았다.
- 스크린샷은 Chrome 캡처 시 높이 재배치가 있어 640×600/500×600이며 별도 육안 확인했다.
