# 좁은 창 시각 개선 결과 — 2026-09-11

이전 점검에서 발견한 파일명 소실, 현재 경로 잘림, 메타데이터 열의 공간 독점을 수정했다.
프런트엔드 배치와 탐색 표시만 변경했으며 실제 파일 작업과 원격 연결 동작은 변경하지 않았다.

## 변경 결과

| 상황 | 현재 동작 |
|---|---|
| 800px 듀얼 패널 + 사이드바 + 미리보기 | 미리보기를 목록 아래에 배치해 양쪽 목록 폭 확보 |
| 창을 다시 넓힘 | 미리보기가 오른쪽으로 돌아오고 저장된 사이드바·미리보기 폭 복원 |
| 사용자가 사이드바를 넓게 저장함 | 좁은 창에서는 표시 폭만 제한. 저장 값은 유지 |
| 목록에 크기·날짜·확장자 열을 표시 | 파일명 영역의 최소 폭 확보, 넘치는 열은 가로 스크롤. 헤더/행 위치 동기화 |
| 긴 경로 | 현재 폴더를 우선 표시. 상위 폴더 메뉴에서 루트/중간 폴더 탐색, 툴팁으로 전체 경로 확인 |
| 패널 폭 420px 이하 | 경로 부가 버튼을 다음 줄로 이동해 새 탭·편집·즐겨찾기·새로고침 접근 유지 |
| 창/패널 크기를 변경함 | 활성 탭을 다시 화면 안으로 스크롤 |

미리보기를 아래에 놓으면 목록의 세로 공간은 줄어든다. 하단 미리보기는 영역 높이의 35%,
최대 240px이며 본문은 스크롤한다. 닫기 버튼을 누르면 목록이 세로 공간을 다시 차지한다.
목록 열을 숨기지는 않으므로 가로 스크롤해 전체 메타데이터와 확장자를 확인할 수 있다.

## 확인

실제 WorkspaceLayout과 패널 컴포넌트를 mock 데이터로 렌더링했다. 이번 fixture에는 실제
중앙 패널 교환 버튼도 포함했다. 실사용 파일·원격 서버에 접근하지 않았다.

- 800×600 다크, 사이드바·듀얼 패널·미리보기: 하단 미리보기, 양쪽 이름 셀(아이콘 포함) 148px,
  문서 가로 넘침 없음. 이전 약 160px 패널 전체 폭에서 파일명이 사라지던 상태를 해소.
- 1440×900 라이트/영문: 오른쪽 미리보기, 양쪽 이름 셀 253px 이상, 문서 가로 넘침 없음.
- 800×600, 저장된 사이드바 420px/미리보기 560px, 확장자·크기·날짜 열 각각 600px:
  표시 폭 자동 제한, 하단 미리보기. 목록/헤더 가로 이동량 각각 1717px로 일치.
  이 이동 검사는 fixture에서 scrollLeft와 scroll 이벤트를 설정했다.
- 800×600 단일 패널, 사이드바 닫힘: 미리보기 오른쪽 배치, 이름 셀 310px.
- 창을 줄였다 넓혀도 저장 폭 및 입력 중인 목록/미리보기 상태를 유지하는 테스트 추가.
- 상위 폴더 메뉴가 POSIX/Windows 경로를 변형하지 않고 탐색 콜백에 전달하는 테스트 추가.

Chrome DOM 측정 높이는 캡처 이미지보다 143px 작다. 위 크기는 이미지 기준이며,
DOM 측정과 육안 확인을 구분했다. 네이티브 Tauri WebView, 실제 PDF/이미지의 하단 미리보기,
고배율·실기 드래그 검증은 별도로 필요하다.
