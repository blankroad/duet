# Duet UX 점검·수정 결과 (2026-11-10 ~ 11-11)

여러 압축 파일의 현재 폴더 해제와 Windows 다중 선택 ‘더보기’를 수정하고, 6개 모듈의 사용 흐름을 점검했다. **Sol 독립 리뷰를 통과하고 실제 검증한 변경만 main에 통합했다.** 미승인 작업은 원본 브랜치와 체크포인트에 보존했다.

## 원래 증상의 변경 결과

- 여러 압축 파일 선택 → 우클릭 → **여기에 압축 풀기**: 현재 폴더에 내용을 풀고 기존 폴더는 병합한다. 충돌 정책은 기본 ‘둘 다 유지’이며, 교체 시 백업·되돌리기를 기록한다. 원본 압축 파일은 보호한다.
- **각각 폴더로 압축 풀기**도 제공한다. 같은 stem의 출력 이름 충돌과 실행 전 이름 선점, 암호 재시도, 일부 항목 실패를 처리한다.
- Windows 로컬 다중 선택에서도 **더보기**가 나타나고 선택 전체를 하나의 네이티브 셸 메뉴에 전달한다. 실행 오류 알림과 빈 공간의 폴더 배경 메뉴도 수정했다.
- 압축/해제 명령을 명령 팔레트에 등록했다. 암호 입력창은 항목별로 분리하며 취소·늦은 응답이 다음 파일의 입력 상태를 건드리지 않는다.

**Windows 반디집/7-Zip 메뉴의 실제 표시·실행은 기기 확인이 남아 있다.** Windows 교차 컴파일과 IPC 모킹 테스트를 통과한 상태다. macOS/Linux의 네이티브 더보기, SSH의 ‘여기에 풀기’는 현재 지원 범위에 포함되지 않는다.

| 최초 증상 통합 수용 테스트 | **4/4 통과** — 압축 3개/일반 파일 혼합, 실제 확인 다이얼로그, 선택 전체 IPC 전달 |

일부 기존 결함 테스트는 `it.fails` 또는 Rust ignore로 남아 있다. 이들의 예상 실패/기본 제외를 해결 건수로 세지 않는다. 수용 테스트는 실제 메인 소스와 생성 바인딩을 대조했지만 IPC는 모킹한다. Rust 테스트는 임시 파일시스템에서 실제 해제·복구·undo를 검증한다.

명령·대상별 수치·로그 해시는 [VALIDATION.json](VALIDATION.json), 커밋/리뷰 매핑은 [INTEGRATION.json](INTEGRATION.json), 최초 증상 근거는 [최종 수용 보고서](research/sol-acceptance-final.md)에 있다. 원본 로그는 로컬 `validation/`에 보존하며 버전 관리에서는 제외했다.

## 미해결·미통합

[중복 제거 후속 대장](research/BACKLOG.md)에 기존 결함, 재현 방식, 담당 영역과 다음 작업을 정리했다. 이번에 시도했으나 통합하지 않은 항목은 다음과 같다.

- 파일 작업 B2: 같은 서버의 자기 자신 복사와 no-op undo 기록 수정은 CHANGES가 남아 있다. 승인된 B1/B3과 분리했다.
- 원격 BE(G-10·링크·검색·sudo): 전체 R2 승인이 완료되지 않았고 취소 순서 테스트와 최종 재실행 근거가 미완료다. FE와 분리해 보존했다.
- 로컬 동기화 복구만 개선했다. 같은 서버 rsync 부분 실패, 목적지 링크 순회, crash-safe journal 등은 후속이다.
- 외부 프로그램의 동시 경로 변경에 대한 보편적인 원자성, 압축 해제 중 세밀한 취소, Windows 실기 동작은 보장 범위가 아니다.

Opus 사용 한도 이후에는 새 구현 모델로 전환하지 않고, 승인된 스냅샷의 테스트·통합과 보고서 정리만 진행했다. 이후 시각의 자동 재개는 취소했다.

## 오케스트레이션과 보존

Herdr `duet` 세션: 중앙 리서치 워크스페이스 1개와 기능별 6개. 각 기능은 Opus 5.5 총괄·구현, Sol 6.1 리뷰 워커를 사용했다. 중앙 대장은 과거 150개 항목과 현재 코드를 대조하고 중복 ID·공유 파일 담당을 정리했다. 변경별 최대 3회 리뷰를 지켰다.

[프로토콜](PROTOCOL.md), [실제 세션 ID](state.json), [조사 대장](research/REGISTRY.md), [기존 이슈 대조](research/opus-prior-issues.md)를 보존한다. 사용자 미커밋 `src-tauri/src/fs/local.rs`는 원본 해시와 일치하며 커밋하지 않았다. 의존성 목록/잠금 파일은 바꾸지 않았다.
