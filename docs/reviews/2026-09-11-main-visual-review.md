# 메인 탐색 화면 시각 점검 — 2026-09-11

> 후속 진행: 아래 초기 점검의 높은 우선순위 3개 항목을 구현했다.
> 현재 동작과 검증은 [좁은 창 개선 결과](2026-09-11-responsive-visual-review.md)를 참고한다.

현재 테마·아이콘·행 간격은 비교적 일관적이다. 완성도를 떨어뜨리는 주된 문제는 장식보다
좁은 폭에서의 정보 배분과 조작부 잘림이다. 알림 개선에 이어 메인 화면을 재현해 점검하고
작은 범위에서 해결 가능한 항목을 수정했다.

## 반영한 수정

| 영역 | 발견한 문제 | 반영 |
|---|---|---|
| 탭 | 여러 탭이 패널 밖으로 밀려 새 탭 버튼 접근 어려움 | 탭 스트립 가로 스크롤, 새 탭 버튼 고정 |
| 활성 탭 | 뒤쪽 탭 선택 시 화면 밖에 남음 | 선택·추가·닫기 시 활성 탭을 스트립 안으로 스크롤 |
| 탭 제목 | 긴 SSH 별칭이 경로와 닫기 버튼을 압박 | 별칭·제목 폭 제한, 탭 최대 폭을 스트립 폭 이내로 제한 |
| 탭 닫기 | 마우스를 올리기 전 활성 탭의 X가 보이지 않음 | 활성 탭 X 상시 표시, 24px 클릭 영역, 키보드 포커스 표시 |
| 패널 도구 모음 | 좁은 폭에서 버튼 자체가 축소됨 | 버튼 28px 유지, 넘칠 때 가로 스크롤, 토글 상태 aria-pressed |
| 미리보기 | 닫기 버튼이 20px로 작음 | 24px로 확대 |
| 상태 표시줄 | 긴 집계/호스트명이 가운데 정보를 밀어냄 | 구역별 폭 제한·축약, 집계/소스 전체 툴팁 |

알림·모달 공통 수정과 검증은 [알림 점검 보고서](2026-09-11-alert-visual-review.md)에 기록했다.

## 아직 남은 개선점

| 우선순위 | 재현/문제 | 권장 방향 |
|---|---|---|
| 높음 | 800px 창에서 사이드바·듀얼 패널·미리보기를 동시에 켜면 패널 폭이 약 160px로 줄어 파일명이 거의 사라짐 | 파일명에 최소 읽기 폭을 보장하고, 부족한 폭에서는 미리보기 오버레이 또는 보조 패널 접기 정책 도입. 사용자 저장 폭/열 너비와 함께 설계 필요 |
| 높음 | 경로 표시줄이 상위 경로부터 잘려 현재 폴더를 알아보기 어려움. 매우 좁은 폭에서는 우측 경로 도구도 잘림 | 현재 폴더를 우선 표시하고 중간 경로를 축약. 부가 조작은 더보기로 이동 |
| 중간 | 최소 창에서 크기·날짜 열이 파일명보다 많은 공간을 차지 | 패널 폭에 따른 열 우선순위 또는 헤더/행이 함께 이동하는 가로 스크롤. 확장자 분리 설정에서도 전체 파일명 식별 보장 |
| 중간 | 아이콘 중심의 도구 모음은 초보자가 의미를 파악하려면 툴팁에 의존. 새 가로 스크롤도 발견성이 약함 | 넘침 메뉴·주요 작업 라벨을 다음 도구 모음 개편 때 함께 검토 |
| 낮음 | 사이드바 빈 상태 설명이 좁은 열에서 여러 줄로 끊김 | 짧은 안내 문구와 명시적인 연결/추가 동작으로 정리 |

위 항목은 발견 사항과 제안이며, 이번에 반영했다고 간주하지 않는다. 특히 최소 창의 파일명
소실은 남아 있다. 모든 창 크기에서 시각 점검을 통과했다는 결론은 아니다.

## 확인 방법과 범위

실제 TopBar, Sidebar, Pane, PreviewPane, StatusBar를 테스트 데이터로 조합하고 프로젝트
Tailwind CSS로 Chrome headless에서 렌더링했다. IPC와 OS 식별은 mock으로 대체했다.
실제 App의 부팅/세션 복원은 실행하지 않았으며 중앙 패널 교환 버튼 등 전체 앱과 차이가 있다.

- 1100×800 다크: 듀얼 패널·사이드바·미리보기, 긴 SSH 별칭, 탭 6개씩, 선택 행.
- 800×600 라이트: 듀얼 패널·사이드바, 긴 파일명, 연결 종료 배너.
- 1440×900 라이트/영문 UI: 마지막 탭 선택 시 양쪽 활성 탭이 스트립 안에 들어옴을 DOM으로 확인.
- 800×600 다크 + 미리보기: 극단적인 폭 부족을 재현. 파일명/경로 문제는 위 후속 항목에 기록.
- 문서 전체 가로 넘침은 위 시나리오에서 없었지만 내부 콘텐츠 잘림은 별도로 육안 확인했다.
- Chrome의 DOM 측정 높이는 캡처보다 143px 작아 화면 크기 표기는 PNG 기준이다.
